# Contributing

This repository is a frozen replication release. For corrections, open an issue describing:

- the affected file or output;
- the command and environment used;
- the observed and expected behavior;
- a minimal reproducible example, when possible.

Changes to data, configurations, estimator code, or reported outputs should be documented in the release notes and accompanied by an updated validation report and SHA-256 manifest. Do not commit local virtual environments, generated `outputs/`, credentials, identifying review correspondence, or machine-specific absolute paths.
